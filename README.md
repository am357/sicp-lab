# SICP-LAB

`sicp-lab` is a tribute to the influential [Structure and Interpretation of Computer Programs (SICP)](https://mitp-content-server.mit.edu/books/content/sectbyfn/books_pres_0/6515/sicp.zip/index.html) book by Abelson, Sussman, and Sussman. Its purpose it to prvide an interactive experince to help the book comprehension.

## Exercises

Just like the book, at the end of each chapter the project provides the list of exercises with the ability to try out and code the problems interactively.

## Playground

The project provides a playground environment that allows to interactively code in `Scheme`. The playground also links to the exercises to provide a convinient way to solving the exercises in one place.
